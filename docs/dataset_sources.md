# Dataset Sources and Provenance

## Primary Dataset

Name: Brazilian E-Commerce Public Dataset by Olist

Official source:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Coverage

The dataset describes historical Brazilian e-commerce marketplace
orders, with order activity primarily spanning 2016–2018.

## Files

Verify the exact filenames and record them here after inspecting
the extracted archive.

Expected table families include:
- Orders
- Customers
- Order items
- Payments
- Reviews
- Products
- Sellers
- Geolocation
- Product category translation

## Data Handling

1. Preserve the downloaded source files unchanged.
2. Record the download date and dataset version when available.
3. Never assume a missing value is an error without investigation.
4. Document exclusions, corrections, and assumptions.
5. Keep generated datasets separate from source files.
6. Do not publish customer-identifying data unnecessarily.
