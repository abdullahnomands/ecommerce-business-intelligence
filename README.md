# E-Commerce Business Intelligence & Analytics

## Project Overview

An end-to-end business analytics project using the Brazilian Olist
e-commerce dataset. The project investigates sales, customers,
products, payments, delivery performance, and customer satisfaction.

## Objectives

- Audit and understand raw data quality.
- Clean and validate data using Pandas and NumPy.
- Perform exploratory data analysis using Matplotlib and Seaborn.
- Define business KPIs with explicit calculation rules.
- Store raw and validated data in PostgreSQL.
- Analyze business performance using SQL.
- Build an interactive Power BI dashboard.
- Communicate evidence-based business recommendations.

## Technology Stack

- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- PostgreSQL
- SQL
- Power BI
- Git and GitHub

## Dataset

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains related tables for orders, customers, products,
sellers, payments, reviews, and other marketplace information.

Review the original dataset license and attribution requirements
before redistributing data or using project outputs commercially.

## Repository Structure

- docs/: business context, data dictionary, and KPI definitions
- notebooks/: data audit, cleaning, and exploratory analysis
- data/raw/: original input files, excluded from Git
- data/processed/: validated outputs, excluded from Git
- sql/: database setup and business analysis queries
- dashboard/: Power BI project documentation
- reports/: findings and final business report

## Data Integrity

Raw files must remain unchanged. Every transformation should be
documented and reproducible. Business metrics must be validated
before publication.
